# My Blocker App

একটি আধুনিক অ্যান্ড্রয়েড অ্যাপ্লিকেশন যা Jetpack Compose এবং Kotlin ব্যবহার করে তৈরি করা হয়েছে। 

## 📱 ফিচারসমূহ (Features)
- আধুনিক ও রেসপনসিভ UI (Jetpack Compose)
- ব্যাকগ্রাউন্ড সার্ভিস ও নোটিফিকেশন সিস্টেম
- ডিভাইস অ্যাডমিন ম্যানেজমেন্ট সাপোর্ট

## 🛠️ প্রযুক্তিগত তথ্যাবলি (Tech Stack)
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **Build System:** Gradle (JDK 17)
- **Architecture:** AndroidX Libraries

## ⚙️ ক্লাউড বিল্ড এবং ইনস্টলেশন (CI/CD)
এই প্রজেক্টটিতে **GitHub Actions** সংযুক্ত করা রয়েছে। রেপোজিটরিতে নতুন কোনো কোড পুশ করা হলে গিটহাবের ক্লাউড সার্ভার অটোমেটিক অ্যাপটি কম্পাইল করে APK বানিয়ে দেয়।

### APK ডাউনলোড করার নিয়ম:
১. এই রেপোজিটরির **Actions** ট্যাবে যান।
২. সবশেষ **Android CI Build** রানটিতে ক্লিক করুন।
৩. একদম নিচে **Artifacts** সেকশনে থাকা **app-debug** ফাইলে ক্লিক করে APK ডাউনলোড করে ফোনে ইনস্টল করুন।
